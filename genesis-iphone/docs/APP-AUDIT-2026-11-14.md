Scope: the iPhone/iPad Genesis Controller app and Mac companion for Mini 1 and Mini 2. This audit does not change Genesis Mini firmware. Mobile build: **0.1.0 (13)**.

## Repairs

- Preserve final words on release, reject stale callbacks after cancellation, and prevent a duplicate release or old authorization callback from interrupting a newer recording.

- Keep mapping and artifact search visible on iPad. Add an accessible artifact refresh label, explicit QR Cancel, and camera/invalid artifact error feedback.

## Real limitations

- **Muse remains unconnected.** Registered artifact browsing is separate from Muse chat controls.
- **Two-way native Voice mode is not implemented.** Hold to Talk is speech-to-text draft capture, followed by explicit Send.
- **Steer is not wired into Genesis.** The installed Codex app-server exposes a turn-specific steer API, but it requires a separate implementation with active-turn validation and duplicate-send protection. The existing queue route must not be presented as Steer.
- **Codex Queued confirms acceptance, not delivery.** Claude delivery can remain uncertain when its UI cannot prove completion. Uncertain messages are not resent automatically.
- **Change model controls the current Codex Mac view.** Its default Control–Shift–M binding must remain available. Reselect a chat if menu navigation clears the mobile route.
- **Artifacts must be registered** with the companion; automatic discovery is not implemented. Photos-library thumbnail navigation still requires the Mac mouse; regular folder navigation is separate.
- No live agent message, permission approval, destructive shortcut, or real microphone session was executed during this audit. The automated evidence does not certify every third-party desktop control or recognition accuracy.

## Reproduce

Run the core, dictation, HTTP and host commands in the repository README. Run the permanent [simulator UI suite](../tests/ui/README.md) against explicit iPhone and iPad simulators.

Real-device follow-up: hold Talk for at least a minute, pause at least five seconds, resume, release, and verify that every phrase remains in the correct chat's draft. Review before any Send. This check is requested once after installation.
